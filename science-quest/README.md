# 사이언스 퀘스트 · 중2 과학

https://gg-web-cmd.github.io/science-quest/

중학교 2학년 과학 여덟 단원을 "연구소"로 하나씩 깨 나가는 픽셀 모험 게임입니다.
비상교육 중학교 과학 2 (2022 개정)의 단원 순서·중단원(블록)·용어·예시를 따랐습니다.

- 캐릭터 만들기 → 과학 섬(마을) → 연구소 8곳(단원) → 구역 3곳(중단원) + 보스 방
- 문제(OX · 골라 보세요 · 계산해 보세요) 253개, 용어 카드 117장, 실험대 미니게임(분류하기 · 순서대로 쌓기) 48개
- 문제를 맞히면 해설과 함께 교과서 쪽수를 알려 줍니다. 보스전 마지막 문제는 교과서 "단원의 문제"입니다.
- 연구소 8곳은 처음부터 모두 열려 있어 지금 배우는 단원으로 바로 들어갈 수 있습니다.
- 보스를 이기면 결과 카드(한 번에 맞힌 비율, 틀린 문제와 해설)가 나오고 그 단원의 열쇠를 얻습니다. 여덟 개를 모으면 완주 인사가 나옵니다.
- 키보드(방향키·Space)와 터치(화면 단추) 모두 됩니다.

## 선생님용

- 수업 시간에 배우는 단원 번호의 연구소로 바로 들어가게 하면 됩니다. 마을의 노란 화살표는 아직 열쇠가 없는 가장 앞 번호 연구소를 가리킵니다.
- 기록은 각자 브라우저(localStorage)에만 남고 서버로 보내는 것은 없습니다. 결과 카드를 캡처해 내게 할 수 있습니다.
- 문제·용어·지도는 단원마다 `js/stages/stageN.js` 한 파일에 들어 있습니다.
