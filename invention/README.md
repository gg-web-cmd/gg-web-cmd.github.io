# 발명특허교실

https://gg-web-cmd.github.io/invention/

아이디어만 있으면 초등학생부터 어른까지 누구나, 쉬운 문장 틀과 개인 생성형 AI의 도움으로 특허청 양식의 명세서를 쓰고 특허로에서 출원까지 하도록 돕는 웹앱입니다. (미성년자는 보호자와 함께)

- 8단계: 문제 찾기 → 아이디어 내기 → 아이디어 고르기 → 구성과 도면 → 선행기술 조사(KIPRIS) → 명세서 쓰기 → 점검하고 보내기 → 출원하기
- 쉬운 말 / 심화 두 가지 설명 수준 (여러 학년이 함께 사용)
- 도면 그림판(부호 붙이기, 사진 흑백 변환), 검색식 자동 생성, 명세서 자동 초안·자동 점검
- 특허청 상용워드 명세서 양식의 워드(.docx)·한글(.hwpx) 파일 내려받기
- 선생님 화면: 학생 프로젝트 파일(.json)을 모아 진행 현황·명세서 미리보기·단계별 코멘트·CSV
- 선행기술조사 보고서(특허 상태·관련도·유사점·차이점·보완점) 보기·인쇄, 제외 검색어(`*!`)
- 학생 출원 비용(만 6~18세 출원료·심사청구료·최초 3년분 등록료 면제)과 출원 후 일정 안내
- 청구항 자동 점검: '상기' 앞 근거(인용 청구항까지), 다중인용, 한 문장, 흐린 표현, 부호와 이름 일치, 도면 언급
- Google Patents 영어 검색어 자동 생성, 마지막으로 검색한 날 기록
- 부품 블록도 자동 그리기, 투상법 안내, AI 그림 초안 확인표(선생님과 함께)
- 대회·전시 전 공지예외 기한 계산, 📓 발명 노트
- 수업 PPT(개정판, 45분 × 6차시)와 같은 흐름·예시 발명. 워드·한글 파일은 학습용 초안이며, 실제 출원은 특허로 공식 템플릿으로 해요
- 문장 틀 청구항: 문장은 그대로, 낱말만 바꿔요. 목록에 없는 내 낱말도 꼴만 맞으면 OK(하는 일 '~는', 연결 '~어/~져', 위치 '의 ○○에'), '상기'는 자동
- 단계마다 '내 맞춤 프롬프트' 복사 → 내가 쓰는 생성형 AI에 붙여 넣기 (웹앱은 AI를 직접 부르지 않아요)
- '누가 쓰나요?' 나이대(초등·중고·19~29·30~64·65세 이상)에 따라 말투·보호자 안내·출원 비용 감면 안내
- 8단계 '실제로 출원하려면' 도우미, '📋 항목별 복사'(특허로 양식에 옮기기), '📖 쉬운 말 사전'

## 데이터
- 웹앱은 AI를 직접 부르지 않고, 입력 내용은 서버로 전송되지 않습니다. 맞춤 프롬프트는 사용자가 직접 복사해 자기 AI에 붙여 넣으며, 이름·연락처 같은 개인정보는 들어가지 않습니다. 각자 브라우저(localStorage)에만 저장됩니다.
- 다른 컴퓨터에서 이어 하거나 선생님께 낼 때는 '파일로 저장'(.json)을 사용합니다.
- 외부로 나가는 것은 학생이 직접 누르는 KIPRIS·Google Patents·특허로 링크뿐입니다. Google Patents 링크에는 학생이 적은 영어 검색어만 들어갑니다.
