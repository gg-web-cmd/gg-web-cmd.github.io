# 발명특허교실

https://gg-web-cmd.github.io/invention/

학생이 생활 속 불편에서 발명 아이디어를 찾고, 특허청 양식의 명세서를 써서, 보호자·교사와 함께 특허로에서 출원까지 하도록 돕는 웹앱입니다.

- 8단계: 문제 찾기 → 아이디어 내기 → 아이디어 고르기 → 구성과 도면 → 선행기술 조사(KIPRIS) → 명세서 쓰기 → 점검하고 보내기 → 출원하기
- 쉬운 말 / 심화 두 가지 설명 수준 (여러 학년이 함께 사용)
- 도면 그림판(부호 붙이기, 사진 흑백 변환), 검색식 자동 생성, 명세서 자동 초안·자동 점검
- 특허청 상용워드 명세서 양식의 워드(.docx)·한글(.hwpx) 파일 내려받기
- 선생님 화면: 학생 프로젝트 파일(.json)을 모아 진행 현황·명세서 미리보기·단계별 코멘트·CSV

## 데이터
- 학생 화면에는 AI가 없고, 입력 내용은 서버로 전송되지 않습니다. 각자 브라우저(localStorage)에만 저장됩니다.
- 다른 컴퓨터에서 이어 하거나 선생님께 낼 때는 '파일로 저장'(.json)을 사용합니다.
- 외부로 나가는 것은 학생이 직접 누르는 KIPRIS·특허로 링크뿐입니다.

## 시연 주소
- 예시 발명을 4단계로 열기: https://gg-web-cmd.github.io/invention/#demo-4
- 선생님 화면 예시: https://gg-web-cmd.github.io/invention/#demo-teacher
