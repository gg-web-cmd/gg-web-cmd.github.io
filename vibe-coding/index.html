바이브 코딩 = 내가 말하고, AI가 만들고, 내가 확인한다 1차시 03–06분

사람 = 기획자 · 검증자
  • 무엇을 만들지 정하고 말로 설명한다
  • 실행해 보고 맞는지 눈으로 확인한다

AI(Claude Code) = 구현자
  • 요청을 코드로 바꾸고 파일을 만든다
  • 필요한 라이브러리를 설치하고 실행한다
  • 오류를 찾아 고친다

① 말하기 → ② 만들기 → ③ 확인하기 → ④ 고치기 — 이 4단계 루프가 오늘 100분 내내 반복됩니다.

① Claude 앱에서 [Code] 탭을 엽니다

  1. 왼쪽 위 </> 버튼 클릭 → Code 탭말풍선 모양은 일반 채팅, </> 모양이 Claude Code

  3. 앱이 바뀔 때마다 새로 생성상장 → 사진 → 타이머 → 퀴즈, 대화를 나눠 쓰면 헷갈리지 않아요

② 작업 폴더 C:\vibe 를 만들고 연결합니다

윈도우 앱 3개, 말로 만들기

웹앱 vs 윈도우 앱, 무엇이 다를까? 1차시 12–14분

색이 칠해진 칸이 더 유리한 쪽입니다.

웹앱 (예: 골든벨 퀴즈 · 2차시)윈도우 앱 (예: 상장 · 사진 · 타이머 · 1차시)
학생이 쓰는 기기● PC · 태블릿 · 휴대폰 · 크롬북Windows PC에서만
인터넷공개 주소로 쓰려면 필요● 없어도 실행
내 컴퓨터 파일고른 파일만 · 폴더 일괄 처리 어려움● 폴더·엑셀·사진을 한꺼번에 처리
학생 개인정보공개 주소에 올리면 안 됨● 내 PC 안에서만 처리
나눠 주기● 링크 · QR 하나로 끝exe · 설치 파일 전달
고친 뒤● 다시 올리면 모두에게 바로 반영새 설치 파일을 다시 나눠 줘야 함
설치 · 보안 경고● 설치 없음백신·SmartScreen 경고가 뜰 수 있음

판단 한 줄   내 컴퓨터의 파일·개인정보를 다루면 → 윈도우 앱  |  여러 사람이 링크로 함께 쓰면 → 웹앱

먼저 규칙부터: CLAUDE.md 1차시 14–17분

CLAUDE.md는 '프로젝트 규칙 메모장'입니다. 한 번 적어 두면 새 대화를 열어도 Claude가 매번 읽고 지킵니다. C:\vibe 폴더를 연결한 상태에서 입력하세요.

프롬프트 0그대로 입력 → Enter
C:\vibe 안에 award, photo, timer, quiz 폴더 4개를 만들어 줘. 그리고 C:\vibe에 CLAUDE.md 파일을 만들어서 아래 규칙을 적어 줘.
1. 파이썬은 Thonny에 들어 있는 python.exe를 찾아서 쓰고, 필요한 라이브러리도 그 파이썬에 설치할 것
2. 한글은 맑은 고딕(malgun.ttf)으로 써서 깨지지 않게 할 것
3. 결과물은 각 앱 폴더 안의 output 폴더에만 저장할 것
4. 엑셀·사진 같은 원본 파일은 절대 수정하지 말 것
5. 만든 뒤에는 직접 실행해서 오류가 없는지 확인할 것

▶ 이렇게 됩니다  C:\vibe에 CLAUDE.md와 폴더 4개가 생깁니다. 이후 모든 대화에서 Claude가 이 규칙을 먼저 읽고 따릅니다.

1번 규칙이 특히 중요해요연수 PC에는 Thonny에 들어 있는 파이썬만 있습니다. 이 규칙이 없으면 파이썬을 못 찾거나 Microsoft Store가 열릴 수 있어요(강사 리허설에서 확인한 함정).

① 상장·수료증 일괄 생성기 1차시 17–35분

엑셀 명단 → 상장 30장, 4번의 대화로 완성합니다. 요령은 1명 미리보기 → 확인 → 전체 생성.

프롬프트 1/4 · 연습용 자료부터 AI에게 18–21분

실제 학생 명단은 쓰지 않습니다. 실습은 항상 가상 데이터로!

프롬프트 1그대로 입력 → Enter
award 폴더에 상장 실습용 자료를 만들어 줘. 가상 학생 30명(이름, 학년, 반, 상 이름)이 들어 있는 students.xlsx 파일과, A4 세로 크기의 상장 배경 이미지 template.png(금색 테두리, 가운데는 비워 두기)를 만들어 줘.

▶ 이렇게 됩니다  award 폴더에 students.xlsx(가상 명단)와 template.png(상장 배경)가 생깁니다. 탐색기에서 열어 확인!

프롬프트 2/4 · 앱의 뼈대: 엑셀 명단을 표로 21–25분

프롬프트 2그대로 입력 → Enter
award 폴더에 파이썬 tkinter로 '상장 만들기' 데스크톱 앱(app.py)을 만들어 줘. '엑셀 명단 선택' 버튼을 누르면 파일 선택 창이 열리고, 고른 엑셀의 명단(이름, 학년, 반, 상 이름)이 창 아래쪽에 표로 보이게 해 줘. 글자는 크게 해 줘.

▶ 이렇게 됩니다  app.py가 생기고, Claude가 직접 실행해 확인합니다. 창이 뜨면 students.xlsx를 골라 명단 30명이 보이는지 확인!

프롬프트 3/4 · 핵심 기능: 먼저 1명만 미리보기 25–28분

프롬프트 3그대로 입력 → Enter
template.png 위에 학생 이름과 '위 학생은 2026학년도 교내 정보 경진대회에서 우수한 성적을 거두었기에 이 상장을 수여함' 문구를 얹어 상장을 만드는 기능을 추가해 줘. 먼저 '미리보기' 버튼을 누르면 표에서 고른 학생 1명의 상장만 창으로 보여 줘.

▶ 이렇게 됩니다  표에서 학생을 고르고 [미리보기]를 누르면 상장 1장이 창에 뜹니다. 한글·위치를 확인하세요.

프롬프트 4/4 · 확인했으면 30명 전원을 한 번에 28–30분

프롬프트 4그대로 입력 → Enter
미리보기 확인했어. '전체 일괄 생성' 버튼을 추가해서 명단 30명 전원의 상장을 PNG와 PDF로 award\output 폴더에 만들어 줘. 파일 이름은 '상장_이름.png'처럼 해 줘.

▶ 이렇게 됩니다  award\output 폴더에 상장 30장(PNG)과 PDF가 생깁니다. 원본 엑셀·배경은 그대로!

Thonny에서 app.py를 열고 ▶ 실행 30–32분

  1. Thonny 실행시작 메뉴에서 Thonny 검색
  2. 파일 > 열기C:\vibe\award\app.py 선택
  3. 초록 ▶ 버튼 (F5)잠시 뒤 '상장 만들기' 창이 뜹니다
  4. 또는 Claude에게"app.py 실행해 줘"라고 말하기

output 폴더에 상장이 만들어졌나요? 32–33분

✔ 확인
  • output에 30장
  • PDF 1개
  • 원본 엑셀·배경 그대로

마음에 안 들면 스크린샷을 붙여 넣고 말하세요 33–34분

스크린샷 수정캡처 붙여넣기 → 문장 입력
(Win + Shift + S로 상장 부분을 캡처 → 입력창에 Ctrl + V)
이 상장에서 이름이 너무 작고 왼쪽으로 치우쳐 있어. 이름 글자를 1.5배 키우고 가로 가운데에 오게 해 줘. 다른 부분은 그대로 둬.

▶ 이렇게 됩니다  Claude가 그림을 보고 위치·크기를 고칩니다. 다시 [미리보기]로 확인 → 괜찮으면 [전체 일괄 생성].
