실습 안내서: https://gg-web-cmd.github.io/vibe-coding/
Claude Code 입력창에 복사해서 붙여 넣으세요. [ ] 부분은 내 정보로 바꿉니다.
작업 폴더: C:\vibe (Claude Code에서 이 폴더를 선택한 상태로 진행)

■ 프롬프트 0
C:\vibe 안에 award, photo, timer, quiz 폴더 4개를 만들어 줘. 그리고 C:\vibe에 CLAUDE.md 파일을 만들어서 아래 규칙을 적어 줘.
1. 파이썬은 Thonny에 들어 있는 python.exe를 찾아서 쓰고, 필요한 라이브러리도 그 파이썬에 설치할 것
2. 한글은 맑은 고딕(malgun.ttf)으로 써서 깨지지 않게 할 것
3. 결과물은 각 앱 폴더 안의 output 폴더에만 저장할 것
4. 엑셀·사진 같은 원본 파일은 절대 수정하지 말 것
5. 만든 뒤에는 직접 실행해서 오류가 없는지 확인할 것

■ 프롬프트 1
award 폴더에 상장 실습용 자료를 만들어 줘. 가상 학생 30명(이름, 학년, 반, 상 이름)이 들어 있는 students.xlsx 파일과, A4 세로 크기의 상장 배경 이미지 template.png(금색 테두리, 가운데는 비워 두기)를 만들어 줘.

■ 프롬프트 2
award 폴더에 파이썬 tkinter로 '상장 만들기' 데스크톱 앱(app.py)을 만들어 줘. '엑셀 명단 선택' 버튼을 누르면 파일 선택 창이 열리고, 고른 엑셀의 명단(이름, 학년, 반, 상 이름)이 창 아래쪽에 표로 보이게 해 줘. 글자는 크게 해 줘.

■ 프롬프트 3
template.png 위에 학생 이름과 '위 학생은 2026학년도 교내 정보 경진대회에서 우수한 성적을 거두었기에 이 상장을 수여함' 문구를 얹어 상장을 만드는 기능을 추가해 줘. 먼저 '미리보기' 버튼을 누르면 표에서 고른 학생 1명의 상장만 창으로 보여 줘.

■ 프롬프트 4
미리보기 확인했어. '전체 일괄 생성' 버튼을 추가해서 명단 30명 전원의 상장을 PNG와 PDF로 award\output 폴더에 만들어 줘. 파일 이름은 '상장_이름.png'처럼 해 줘.

■ 스크린샷 수정
(Win + Shift + S로 상장 부분을 캡처 → 입력창에 Ctrl + V)
이 상장에서 이름이 너무 작고 왼쪽으로 치우쳐 있어. 이름 글자를 1.5배 키우고 가로 가운데에 오게 해 줘. 다른 부분은 그대로 둬.

■ 오류 붙여넣기
app.py를 실행했더니 아래 오류가 났어. 원인을 찾아서 고쳐 줘. 다른 기능은 바꾸지 마.
(오류 메시지 전체를 복사해서 붙여 넣기)

■ 프롬프트 5
photo 폴더 안의 sample_photos 폴더에 연습용 가상 사진 30장을 만들어 줘. 사람 얼굴 없이 풍경·도형 그림으로, 크기는 제각각(가로 1600~2600픽셀)으로 해 줘.

■ 프롬프트 6
photo 폴더에 tkinter로 '사진 일괄 정리 도구'를 만들어 줘. 날짜와 행사명을 입력하고 폴더를 고르면, 그 안의 사진을 '날짜_행사명_번호.jpg'(예: 20260710_체육대회_001.jpg)로 이름을 바꾸고 가로 1280픽셀로 줄여서 output 폴더에 저장해 줘. 원본 사진은 절대 건드리지 마.

■ 프롬프트 7 · 도전
실제로 바꾸기 전에 '원래 파일명 → 새 파일명' 목록을 먼저 보여 주고, 내가 [실행] 버튼을 눌러야 변환되도록 미리보기 기능을 추가해 줘.

■ 프롬프트 8
timer 폴더에 '쉬는 시간 알림' 앱을 만들어 줘. 평소에는 창 없이 작업 표시줄 트레이 아이콘으로 숨어 있다가, 정해 둔 시각(예: 매시 50분)이 되면 '쉬는 시간입니다!' 알림창을 맨 앞에 띄우고 알림음을 울려 줘. 트레이 아이콘을 우클릭하면 시각 설정, 지금 알림 테스트, 종료를 할 수 있게 해 줘.

■ 프롬프트 9
award의 상장 만들기 앱을 PyInstaller로 exe 파일 하나로 만들어 줘. 콘솔 창은 뜨지 않게 하고, template.png도 exe 안에 넣어 줘. 결과물은 exe 옆 output 폴더에 저장되게 하고, 빌드한 exe를 직접 실행해서 확인해 줘.

■ 프롬프트 10
이 exe로 Inno Setup 설치 파일(setup.exe)도 만들어 줘. 한국어 설치 화면, 관리자 권한 없이 설치, 바탕화면·시작 메뉴 바로가기, 제어판에서 제거 가능하게 해 줘. Inno Setup(ISCC.exe)은 %LOCALAPPDATA%\Programs\Inno Setup 6 또는 C:\Program Files (x86)\Inno Setup 6에 있어. 확인 없이 끝까지 진행해 줘.

■ 프롬프트 11
quiz 폴더에 골든벨 퀴즈 웹앱을 index.html 파일 하나로 만들어 줘(CSS·JS도 그 안에). 중학교 정보 '자료와 정보' 단원 4지선다 5문제를 한 문제씩 크게 보여 주고, 답을 고르면 정답은 초록색·오답은 빨간색으로 바로 알려 줘. 마지막에는 총점과 격려 문구를 보여 줘. 교실 TV에 띄울 거라 글자를 크게 해 줘.

■ 프롬프트 12
문제를 내 교과인 [과목·단원] 내용으로 바꿔 줘. 문제 수는 10개로 늘리고, 나머지 디자인과 기능은 그대로 둬.

■ 프롬프트 13
