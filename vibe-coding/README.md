# 나만의 앱 만들기 (vibe coding)

교사 대상 바이브 코딩 연수(2차시) 실습 안내서입니다.

- 실습 페이지: https://gg-web-cmd.github.io/vibe-coding/
- Claude Code로 윈도우 앱 3개(상장 생성기 · 사진 정리 · 쉬는 시간 타이머)를 만들고, 설치 파일(exe → setup.exe)로 배포한 뒤, 웹앱(골든벨 퀴즈)을 GitHub Pages로 공개하는 흐름
- 연수에서 사용한 PPT와 같은 순서 · 같은 프롬프트(0~15)로 구성
- 프롬프트 복사 버튼, GitHub 아이디 입력 시 프롬프트 자동 완성, 진행 체크(브라우저에만 저장)
- 골든벨 퀴즈 완성 예시: `demo/quiz/`
- 프롬프트 모음: `downloads/prompts.txt`
