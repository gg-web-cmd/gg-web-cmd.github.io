#

문서 MD 변환기

한글(HWPX)·PDF·워드·PPT·엑셀 문서를 AI가 읽기 좋은 마크다운(.md)으로 바꾸고, 쪽마다 얼마나 잘 옮겨졌는지 진단합니다.

파일은 이 브라우저 안에서만 변환되고 어디에도 올라가지 않습니다

결과 파일에 넣을 내용

변환 목록

    • 옛 한글 파일(.hwp)은 한글에서 [다른 이름으로 저장] → HWPX로 저장한 뒤 넣어 주세요.
    • 스캔하거나 사진으로 만든 PDF는 읽을 글자가 없어 거의 빈 결과가 나옵니다.
    • 수학·과학 자료는 PDF보다 HWPX가 정확합니다. 수식이 LaTeX로 옮겨집니다.
    • 전환율은 그림·도표·병합 셀·스캔 쪽을 보고 추정한 값입니다.
